What's real, what's mocked

Read this before you judge anything on this page.

Real and working

  • Jurisdiction routing, confidence and reasoning — a live call to an OpenAI model against a curated department taxonomy.
  • Detection of state-subject grievances that do not belong on CPGRAMS at all.
  • Detection of complaints whose correct venue is a sectoral ombudsman rather than a grievance portal.
  • Bilingual complaint drafting in the structure a receiving officer expects.
  • Speech input, where the browser supports it.
  • Escalation logic and the drafted first appeal.

Mocked or simplified

  • Nothing is filed. There is no connection to CPGRAMS, any ministry, or any state portal. No request leaves this site except the model call.
  • Registration numbers are generated locally and prefixed MOCK.
  • Officer designations, statuses and file movement entries are synthetic.
  • The department taxonomy is a curated subset of high-volume categories, not the full government directory.
  • SLA of 21 days and appeal window of 30 days follow the published CPGRAMS norms, but real timelines vary by department.
  • Routing accuracy has not been measured against a labelled grievance dataset. We have tested it by hand only.
  • The time control on the tracking page fast-forwards a simulated clock.
  • If the model key is unavailable, the app falls back to a canned routing result so the journey still completes. It says so on screen when that happens.

How this would work at scale

This is a layer in front of the existing portal, not a replacement. Every grievance a department transfers away is already a labelled example of a misroute, so the classifier can be trained and continuously evaluated on the government's own transfer history. Each prevented misroute saves a manual transfer at the receiving end and weeks at the citizen's end. Rollout would start read-only: suggest the category, let the citizen confirm, measure transfer rates against a control group before automating anything.
